# 📊 Credit Rating Prediction using Machine Learning

This project uses financial data and machine learning to **predict corporate credit ratings**, enabling early identification of high-risk firms. It focuses on building a robust, interpretable model using financial ratios and modern classification techniques.

---

## 🔍 Problem Statement

Credit rating agencies assign scores to companies based on their financial health. This model predicts those scores using publicly available financial metrics, helping investors and analysts gauge creditworthiness without relying solely on third-party ratings.

---

## 🧠 Key Highlights

- Trained multiple classifiers (Logistic Regression, Random Forest, XGBoost) on labeled financial data
- Handled class imbalance using **SMOTE** and **grouped label simplification**
- Used **feature engineering** and **financial ratios** to improve model relevance
- Interpreted predictions with **SHAP values** for transparency
- Achieved high precision and recall, especially for identifying high-risk (low-rated) firms

---

## 🛠️ Tech Stack

- Python, Pandas, Scikit-learn, XGBoost
- SMOTE for oversampling
- SHAP for explainability
- Matplotlib, Seaborn for visualizations

---

## 📈 Evaluation Metrics

- Accuracy  
- Precision / Recall (focus on low-credit score recall)  
- Confusion matrix  
- SHAP summary plots
